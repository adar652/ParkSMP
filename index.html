What is ParkSMP?

ParkSMP is an Aternos server in Minecraft.


What is Aternos?

Aternos is a website that lets you create Minecraft servers for free.


Voice Chat

ParkSMP supports voice chat.


To use voice chat, install VCMC. After completing the requirements, add a server named ParkSMP.aternos.me. Copy the verification command generated by VCMC and paste it into the ParkSMP chat. Before pasting the command into chat, make sure that WebSocket is enabled.
